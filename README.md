# تاريخ المنتج | Product Date QR

مشروع تجريبي مجاني لإنشاء صفحة معلومات منتج ورمز QR باستخدام HTML وCSS وJavaScript، ويمكن نشره على GitHub Pages.

## الملفات
- `index.html` — صفحة معلومات المنتج التي تفتح عند مسح QR.
- `admin.html` — لوحة إدخال بيانات المنتج وإنشاء الرابط ورمز QR.
- `style.css` — تصميم الصفحات.
- `script.js` — التحقق من المدخلات، إنشاء الروابط، QR، وسجل المتصفح.

## اسم المستودع المقترح
`product-date-qr`

## النشر على GitHub Pages
1. أنشئ مستودعًا عامًا جديدًا باسم `product-date-qr`.
2. ارفع الملفات الأربعة إلى جذر المستودع، وليس داخل مجلد إضافي.
3. افتح **Settings → Pages**.
4. في **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.
6. بعد النشر، افتح `https://YOUR-USERNAME.github.io/product-date-qr/`.
7. لوحة الإدارة: `https://YOUR-USERNAME.github.io/product-date-qr/admin.html`.

استبدل `YOUR-USERNAME` باسم حساب GitHub الجديد.

## تنبيه مهم
هذا نموذج تعليمي فقط. سجل المنتجات محفوظ في `localStorage` داخل المتصفح الحالي، ولا تتم مزامنته بين الأجهزة أو المستخدمين. بيانات المنتج الموجودة في رابط QR يمكن تغييرها؛ لذلك لا تستخدم هذا النموذج كنظام رسمي للمصانع أو لقرارات سلامة الأغذية. للاستخدام الحقيقي ستحتاج إلى خادم وقاعدة بيانات وتحقق من صلاحيات تعديل البيانات.
